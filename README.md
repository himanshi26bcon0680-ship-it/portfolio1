# portfolio1

> Personal Portfolio of Himanshi ✨ — CS & AI Scholar, Computer Vision Engineer & UI Designer.

## 🌟 Overview
Welcome to my personal portfolio repository! This project showcases my journey in Computer Science & Artificial Intelligence, highlighting featured projects, technical capabilities, interactive demos, and design philosophy.

## 🛠️ Tech Stack
- **HTML5 & Vanilla CSS**: Fast, modern, responsive glassmorphic design
- **Vanilla JavaScript**: Interactive components, filtering, and live chat simulation
- **GSAP & ScrollTrigger**: Smooth entrance and scroll-based micro-animations
- **Google Fonts**: Outfit, Plus Jakarta Sans, Space Grotesk

## 📂 Project Structure
```
portfolio/
├── index.html    # Core structure and sections
├── style.css     # Design system, variables, and styling
├── script.js     # Interactivity, GSAP animations, AI chat demo
└── README.md     # Project documentation
```

## 🚀 Getting Started
To view the portfolio locally:
1. Clone or download this repository.
2. Open `index.html` in your web browser (or serve with any static server like VS Code Live Server).
